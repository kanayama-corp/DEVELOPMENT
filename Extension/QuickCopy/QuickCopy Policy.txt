# QuickCopy プライバシーポリシー

最終更新日: 2025年8月27日

このプライバシーポリシーは、Chrome拡張機能「QuickCopy」（以下、「本拡張機能」）が収集する情報と、その情報の使用方法について説明します。

## 1. 収集する情報

本拡張機能は、以下の情報を収集・利用します。

- **ユーザー設定情報**: 拡張機能のオプションページでユーザーが設定した内容（自動コピーの有効/無効、コピー方法の選択など）を、お使いのブラウザの `chrome.storage.sync` API を使用して保存します。
- **クリップボード情報**: Googleスプレッドシート上でテキストをコピーする際に、一時的にクリップボードへのアクセス (`clipboardRead`) を行います。これは、スプレッドシートのセルから選択内容を正確に取得する目的でのみ使用されます。

## 2. 情報の利用目的

収集した情報は、以下の目的のためにのみ利用します。

- 拡張機能の基本機能を提供するため。
- ユーザーの設定を保存し、利便性を向上させるため。

## 3. 情報の共有と第三者への提供

本拡張機能は、ユーザーの情報を販売、交換、またはその他の方法で第三者に譲渡することはありません。収集したすべてのデータは、ユーザーのローカルブラウザ内またはGoogleアカウントの同期ストレージ内にのみ保持され、外部のサーバーに送信されることは一切ありません。
