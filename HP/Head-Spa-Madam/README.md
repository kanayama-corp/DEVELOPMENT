## 🚀 セットアップ

### 前提条件
- モダンなウェブブラウザ
- ローカルサーバー（開発用）

### インストール手順

1. **ファイルのダウンロード**
   ```bash
   # このフォルダをローカルにコピー
   cp -r luxury-head-spa-kobe/ your-project-folder/
   cd your-project-folder
   ```

2. **ローカルサーバーの起動**
   ```bash
   # Python 3の場合
   python -m http.server 8000
   
   # Python 2の場合
   python -m SimpleHTTPServer 8000
   
   # Node.jsのlive-serverを使用する場合
   npx live-server
   ```

3. **ブラウザでアクセス**
   ```
   http://localhost:8000
   ```
