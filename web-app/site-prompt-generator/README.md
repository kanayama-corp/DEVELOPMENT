# 🎨 サイト類似プロンプト生成ツール

参考にしたいウェブサイトのURLを入力するだけで、Windsurf・Cursor用の類似サイト作成プロンプトを自動生成するツールです。

## ✨ 機能

- **最大5つのURL入力**: 参考にしたいサイトを最大5つまで入力可能
- **自動サイト分析**: 入力されたURLのサイト情報を分析
- **プロンプト自動生成**: WindsurfとCursor向けの最適化されたプロンプトを生成
- **ワンクリックコピー**: 生成されたプロンプトを簡単にコピー
- **レスポンシブデザイン**: モバイル・タブレット・デスクトップ対応

## 🚀 使い方

1. **URLの入力**: 参考にしたいサイトのURLを入力欄に入力
2. **サイト分析**: 「分析」ボタンをクリックしてサイト情報を取得
3. **プロンプト生成**: 「プロンプト生成」ボタンをクリック
4. **コピー**: WindsurfまたはCursor用のタブを選択して「コピー」ボタンをクリック
5. **AI開発ツールで使用**: コピーしたプロンプトをWindsurfやCursorに貼り付けて使用
