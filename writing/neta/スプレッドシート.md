高速移動

表の最初に戻る
　Windows・Chrome OS：Ctrl + Home
　Mac：⌘ + Home
　使う場面：A1セルに瞬時に戻りたい時

表の最後に移動
　Windows・Chrome OS：Ctrl + End
　Mac：⌘ + End
　使う場面：データが入力されている最後のセルに移動したい時

便利な入力機能

データの端まで選択範囲を拡張
　Windows・Chrome OS：Ctrl + Shift + 矢印キー
　Mac：⌘ + Shift + 矢印キー
　使う場面：大きなデータ範囲を一気に選択したい時


数値の表示形式

パーセント表示
　Windows・Chrome OS：Ctrl + Shift + %
　Mac：⌘ + Shift + %
　使う場面：割合や比率を表示したい時

通貨表示
　Windows・Chrome OS：Ctrl + Shift + $
　Mac：⌘ + Shift + $
　使う場面：金額や価格を表示したい時

書式のコピー

書式をコピー
　Windows・Chrome OS：Ctrl + Alt + C
　Mac：⌘ + Option + C
　使う場面：セルの見た目だけをコピーしたい時

書式を貼り付け
　Windows・Chrome OS：Ctrl + Alt + V
　Mac：⌘ + Option + V
　使う場面：コピーした書式を他のセルに適用したい時

構造編 行・列を操作する

行の操作

行を上に挿入
　Windows・Chrome OS：Alt + I, R（AltとIを同時に押した後、R）
　Mac：Control + Option + I, R
　使う場面：データの間に新しい行を追加したい時

行を削除
　Windows・Chrome OS：Alt + E, D（AltとEを同時に押した後、D）
　Mac：Control + Option + E, D
　使う場面：不要な行を削除したい時

列の操作

列を左に挿入
　Windows・Chrome OS：Alt + I, C（AltとIを同時に押した後、C）
　Mac：Control + Option + I, C
　使う場面：データの間に新しい列を追加したい時

列を削除
　Windows・Chrome OS：Alt + E, L（AltとEを同時に押した後、L）
　Mac：Control + Option + E, L
　使う場面：不要な列を削除したい時

表示の切り替え

行を非表示
　Windows・Chrome OS：Ctrl + Alt + 9
　Mac：⌘ + Option + 9
　使う場面：一時的に特定の行を隠したい時

列を非表示
　Windows・Chrome OS：Ctrl + Alt + 0
　Mac：⌘ + Option + 0
　使う場面：一時的に特定の列を隠したい時

非表示の行を再表示
　Windows・Chrome OS：Ctrl + Shift + 9
　Mac：⌘ + Shift + 9
　使う場面：隠していた行を再び表示したい時

非表示の列を再表示
　Windows・Chrome OS：Ctrl + Shift + 0
　Mac：⌘ + Shift + 0
　使う場面：隠していた列を再び表示したい時

応用編 高度な機能を活用する

データ分析

データ探索を開く
　すべてのOS：Alt + Shift + X
　使う場面：AIにグラフや分析結果を自動生成してもらいたい時

フィルターの切り替え
　Windows・Chrome OS：Ctrl + Alt + Shift + F
　Mac：⌘ + Option + Shift + F
　使う場面：データの絞り込み機能をオンオフしたい時

並び替えダイアログを開く
　Windows・Chrome OS：Alt + D, S（AltとDを同時に押した後、S）
　Mac：Control + Option + D, S
　使う場面：複数の条件でデータを並び替えたい時

コメントと履歴

コメントを挿入
　Windows・Chrome OS：Ctrl + Alt + M
　Mac：⌘ + Option + M
　使う場面：セルに注釈やメモを追加したい時

変更履歴を表示
　Windows・Chrome OS：Ctrl + Alt + Shift + H
　Mac：⌘ + Option + Shift + H
　使う場面：誰がいつ何を変更したかを確認したい時

画面表示

ズームイン
　Windows・Chrome OS：Ctrl + +
　Mac：⌘ + +
　使う場面：画面を拡大して見やすくしたい時

ズームアウト
　Windows・Chrome OS：Ctrl + -
　Mac：⌘ + -
　使う場面：全体を俯瞰して確認したい時

標準表示に戻す
　Windows・Chrome OS：Ctrl + 0
　Mac：⌘ + 0
　使う場面：拡大・縮小後に通常の表示に戻したい時

印刷関連

印刷プレビューを開く
　Windows・Chrome OS：Ctrl + P
　Mac：⌘ + P
　使う場面：印刷前に仕上がりを確認したい時

箇条書き機能

箇条書きを作成
　Windows・Chrome OS：Ctrl + Shift + 8
　Mac：⌘ + Shift + 8
　使う場面：セル内でリスト形式の文字を入力したい時

番号付きリストを作成
　Windows・Chrome OS：Ctrl + Shift + 7
　Mac：⌘ + Shift + 7
　使う場面：セル内で順序のあるリストを作成したい時

インデントを下げる
　すべてのOS：Tab または Ctrl + ]
　使う場面：箇条書きの項目をより詳細なレベルにしたい時

インデントを上げる
　すべてのOS：Shift + Tab または Ctrl + [
　使う場面：箇条書きの項目を上位レベルに戻したい時
