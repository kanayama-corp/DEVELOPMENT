置換して貼り付け(わぴこ)


表の最初に戻る
　Windows・Chrome OS：Ctrl + Home
　Mac：⌘ + Home
　使う場面：A1セルに瞬時に戻りたい時

表の最後に移動
　Windows・Chrome OS：Ctrl + End
　Mac：⌘ + End
　使う場面：データが入力されている最後のセルに移動したい時

便利な入力機能

データの端まで選択範囲を拡張
　Windows・Chrome OS：Ctrl + Shift + 矢印キー
　Mac：⌘ + Shift + 矢印キー
　使う場面：大きなデータ範囲を一気に選択したい時

データ探索を開く
　すべてのOS：Alt + Shift + X
　使う場面：AIにグラフや分析結果を自動生成してもらいたい時

フィルターの切り替え
　Windows・Chrome OS：Ctrl + Alt + Shift + F
　Mac：⌘ + Option + Shift + F
　使う場面：データの絞り込み機能をオンオフしたい時

並び替えダイアログを開く
　Windows・Chrome OS：Alt + D, S（AltとDを同時に押した後、S）
　Mac：Control + Option + D, S
　使う場面：複数の条件でデータを並び替えたい時

コメントと履歴

コメントを挿入
　Windows・Chrome OS：Ctrl + Alt + M
　Mac：⌘ + Option + M
　使う場面：セルに注釈やメモを追加したい時

変更履歴を表示
　Windows・Chrome OS：Ctrl + Alt + Shift + H
　Mac：⌘ + Option + Shift + H
　使う場面：誰がいつ何を変更したかを確認したい時



印刷関連

印刷プレビューを開く
　Windows・Chrome OS：Ctrl + P
　Mac：⌘ + P
　使う場面：印刷前に仕上がりを確認したい時
